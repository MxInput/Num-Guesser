## Num Guesser

A game where you have to guess 4 randomly generated numbers within 6 guesses. After each guess you are told whether the number you chose for a specific position is greater than, less than, or equal to the actual number in that spot as clues to figure out the answer.

Made in Godot

Get the game here: https://mxinput.itch.io/num-guesser
